# Sai-Swetha-Portfolio
Personal Portfolio Website

This is my personal portfolio website developed using HTML, CSS, and JavaScript to showcase my profile, skills, qualifications, and projects in a clean and responsive single-page design.

The portfolio includes a Home section with a short introduction, profile image, and contact button, followed by sections such as About Me, Skills, Qualifications, Projects, and Contact. Smooth scrolling navigation allows easy movement between sections.

The website is fully responsive, works across different screen sizes, and follows a modern UI layout. It also includes interactive elements and organized styling to enhance user experience.

🛠️ Technologies Used

HTML5

CSS3

JavaScript

 Purpose

To present my academic background and technical skills

To highlight projects and achievements

To serve as an online resume and professional profile
